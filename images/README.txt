Taruh gambar destinasi di sini.

Nama file = nama wisata (bagian sebelum koma pertama) yang di-slug:
huruf kecil, spasi/simbol jadi tanda minus.
  "Desa Adat Wae Rebo"   -> desa-adat-wae-rebo.jpg
  "Desa Wisata Melo"     -> desa-wisata-melo.jpg
  "Pulau Padar"          -> pulau-padar.jpg
Format: jpg / jpeg / png / webp.

Alternatif: tambah kolom "Gambar" di CSV berisi nama file-nya.

Background halaman pencarian: background.jpg
